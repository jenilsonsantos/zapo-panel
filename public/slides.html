WhatsApp direto do seu código

Hoje o papo é controle total: a zapo-js, uma biblioteca TypeScript que implementa o protocolo do WhatsApp Web dentro do seu próprio app — sem servidor intermediário. E, para provar, vamos construir do zero o zapo-panel: painel + bot, pronto para você baixar e rodar.

zapo-js, a biblioteca
TypeScript · Node 20.9+ · MIT · github.com/vinikjkkj/zapo
  • Protocolo WhatsApp Web completo: QR, Signal (e2e), mídia, grupos
  • Multi-sessão no mesmo processo, com stores plugáveis
  • Docs com servidor MCP para usar com IA (zapo.to)
zapo-panel, o projeto de hoje
JavaScript puro · zero build · comentado em português
  • Painel web: QR na tela, conversas ao vivo, filtros do bot
  • Bot de comandos: botões, lista, enquete, reação, "digitando..."
  • Roda com npm start ou docker compose up -d
O conceito em uma frase
API pronta (REST)

Um servidor entre
você e o WhatsApp

Você sobe um serviço, cria instâncias e conversa com ele por endpoints e webhooks. A lógica do WhatsApp mora fora do seu código.

zapo-js

Uma biblioteca
dentro do seu app

npm install zapo-js e pronto: eventos e envios acontecem no seu próprio processo Node. Sem serviço intermediário, sem instância, sem webhook — só JavaScript.

Os dois modelos se completam. APIs prontas embalam uma biblioteca num servidor para você só consumir. A zapo-js é a camada de baixo: perfeita quando você quer controle total — e é o seu sistema que manda.
Stack técnica

O que a zapo-js entrega

Reimplementação independente do protocolo, com foco em desempenho e multi-sessão.

zapo-js
LinguagemTypeScript · Node 20.9+ (funciona em JS puro)
ProtocoloWhatsApp Web: Noise + Signal (criptografia de ponta a ponta)
PareamentoQR code ou código de 8 dígitos
SessõesVárias contas no mesmo processo (sessionId)
PersistênciaSQLite, Redis, MongoDB, MySQL ou PostgreSQL
MensagensTexto, mídia, reação, enquete, botões e listas (proto bruto)
ExtrasGrupos, newsletters, presença, VoIP via plugin, aceleração em Rust
LicençaMIT — docs em zapo.to
O projeto

zapo-panel: 6 arquivos, zero build

Feito para iniciante: JavaScript puro, comentários em português, cada arquivo com uma responsabilidade só.

ArquivoO que faz
server.jsExpress + Socket.IO: entrega o painel e conversa com o navegador em tempo real
whatsapp.jsConexão zapo-js: QR, pareamento, reconexão, repasse de mensagens
comandos.jsO cérebro do bot: roteia !ping, !menu, cliques de botão e lista
mensagens.jsFunções prontas de envio: texto, reply, botões, lista, enquete, reação
configuracao.jsFiltros de quem o bot responde (pessoas e grupos), salvos em JSON
public/O painel: HTML, CSS e JS puros — sem framework, sem build
Quer mudar o bot? Só mexer no comandos.js — e com npm run dev o servidor reinicia sozinho a cada arquivo salvo.
Demo ao vivo

O que o bot responde

Cada comando demonstra um recurso diferente da lib — do texto simples ao proto bruto.

ComandoRecurso demonstrado
!pingReceber e enviar mensagem + reação na mensagem original
!menuReply (resposta citando a mensagem)
!botoesBotões clássicos Sim/Não via buttonsMessage
!listaMenu de lista (pizzaria com seções) via listMessage
!linkBotão de URL moderno via interactiveMessage (nativeFlow)
!enqueteEnquete com votação dentro do WhatsApp
Transparência: botões e listas dependem do aparelho e do tipo de conta — o WhatsApp não renderiza em todo cliente. Vamos testar ao vivo e mostrar o resultado real, sem cortes.
O painel

Uma "mini plataforma" no navegador

Tudo que a lib emite vira interface: sidebar corporativa, ícones Lucide, Socket.IO por baixo.

Operação
  • QR code na tela e status ao vivo (aguardando / conectado / caiu)
  • Conversas em tempo real: chats agrupados, bolhas, envio manual
  • Métricas da sessão: recebidas e enviadas
Controle do bot
  • Pessoas: responder todos ou só números autorizados
  • Grupos: todos, nenhum, ou marcar grupos específicos pelo nome
  • Tudo salvo em bot-config.json — sobrevive a restart
O filtro vale para as respostas do bot: as mensagens de todo mundo continuam aparecendo no painel normalmente.
Docs com IA

A doc do zapo dentro do seu assistente (MCP)

O repositório já traz um .mcp.json apontando para o servidor MCP oficial da documentação. O assistente passa a consultar a doc real antes de gerar código — em vez de inventar API.

Claude Code

claude mcp add zapo-docs --scope user \
  --transport http https://zapo.to/mcp

{
  "mcpServers": {
    "zapo-docs": { "url": "https://zapo.to/mcp" }
  }
}
Demo na live: vamos pedir "crie um comando !figurinha consultando a doc do zapo" e ver a IA buscar a página certa da documentação sozinha.
Passo a passo

Rode na sua máquina

Dois caminhos: Node direto (recomendado para mexer no código) ou Docker (para deixar rodando).

  1. Baixe o projeto — git clone ou o botão Code › Download ZIP no repositório (link na descrição).
  2. Com Node 20.9+ instalado, dentro da pasta: 
    npm install
npm start        # ou: npm run dev (reinicia sozinho ao salvar)
    Prefere Docker? Pula o Node: docker compose up -d — a sessão fica num volume, o config fica na pasta.
  3. Abra o painel em http://localhost:3333.
  4. Escaneie o QR com o WhatsApp: Configurações › Aparelhos conectados › Conectar aparelho.
  5. Mande !menu para o número conectado (de outro celular) e brinque com os comandos.
Use um chip de teste. Biblioteca não-oficial = risco de banimento. Nada de número principal, nada de spam. Projeto educacional.
