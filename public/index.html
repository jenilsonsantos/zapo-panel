Comandos disponíveis

Envie qualquer um destes comandos para o número conectado (a partir de outro celular). A lógica de cada um está no arquivo comandos.js.

ComandoO que faz
!pingTeste de vida: o bot reage à sua mensagem e responde "pong".
!menuLista de comandos, respondida como reply da sua mensagem.
!botoesMensagem interativa com botões de Sim e Não.
!listaCardápio de pizzaria com seções e itens selecionáveis.
!linkBotão que abre o canal do YouTube.
!enqueteEnquete de sabores com votação dentro do WhatsApp.

Botões e listas podem não renderizar em todo aparelho ou tipo de conta. É uma limitação do próprio WhatsApp, não do projeto.

      Documentação com IA (MCP)

      Este projeto já vem com um servidor MCP configurado: o arquivo .mcp.json na raiz aponta para https://zapo.to/mcp, a documentação oficial da zapo-js. Com ele, o seu assistente de código consulta a doc de verdade antes de gerar código — em vez de inventar API que não existe.

      Claude Code

      Abra a pasta do projeto e aprove o servidor zapo-docs quando ele perguntar. Para ter em qualquer projeto:

      claude mcp add zapo-docs --scope user --transport http https://zapo.to/mcp

      Cursor

      Adicione ao arquivo ~/.cursor/mcp.json:

      {
  "mcpServers": {
    "zapo-docs": { "url": "https://zapo.to/mcp" }
  }
}

      Teste na prática: peça "crie um comando !figurinha no comandos.js consultando a documentação do zapo" e veja a IA buscar a página certa da doc sozinha.
